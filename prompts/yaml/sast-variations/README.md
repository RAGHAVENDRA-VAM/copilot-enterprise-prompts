# SAST Tool Variations

This directory contains YAML prompt variations for different SAST tools.

## Available SAST Tools

Each prompt file includes specific configuration for:

- **SonarQube** - Code quality and security analysis
- **Snyk** - Dependency and container scanning
- **CodeQL** - GitHub native security scanning
- **Semgrep** - Lightweight static analysis

## How to Use

1. Choose your SAST tool
2. Select the appropriate prompt file
3. Replace placeholders with your values
4. Copy prompt to Copilot

## File Naming Convention

`<language>-<platform>-<sast-tool>.md`

Example: `nodejs-azure-sonarqube.md`
